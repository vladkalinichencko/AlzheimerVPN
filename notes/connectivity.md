## Persistent connection logging

The macOS client and service initialize logging independently of the detailed-debug setting. Info, warning, and error messages are always saved. The existing switch adds debug messages; disabling it preserves the connection journal. The 14-day automatic log deletion is bypassed for this macOS build. Recorded events include protocol/server/DNS selection, lifecycle and health changes, recovery attempts, DNS lookup durations and errors, connectivity checks, resolver changes, physical routes, sleep, and wake readiness.

The existing logger writes UTC hourly files under its original client and service log folders. Each line is flushed, and a recursive mutex serializes file access from Qt worker and power-notification threads. Rotation happens on the next write after an hour boundary, including after sleep. Files older than the hour containing the 24-hour cutoff are deleted, retaining 24–25 hours. Exports concatenate retained hours in chronological order. The logging settings page explains the permanent journal and labels the switch as detailed logging.
